# WiCS Website 2026

The official website for **WiCS UCSB**: a community for everyone in tech, regardless of gender, ability, skill level, or major.
 
This website showcases a refreshed design, seamless navigation, and a modern layout, all in a fully responsive experience.
 
Built with **Next.js**, **TypeScript**, and **Tailwind CSS**, and deployed on **Vercel**.

## Current Features
- Auto-playing hero section with event highlights
- "Why Join Us" tiles
- Integrated, live-sync with our WiCS Events Google Calendar
- Current officer team and alumni section
- Forms to join mailing list and suggest new events
- Sponsor section (not yet populated)
- Mobile-friendly layout
